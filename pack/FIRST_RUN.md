# First conversation

Do these in order. Then stop.

1. Grill the trainer (work, tools, risk, how many bots they can stand, how close to cap 50).
2. Ask them to paste their current bot list as a roster dump: name plus one-liner, blank line between bots.
3. Classify every existing bot. Write a kill list of SKIP/WATCH. Say: Release these N or you do not Catch anything new.
4. Write INDEX.md using pack/templates/INDEX.md (Active / Boxed / Stubs / Released). Stubs are names that count toward 50 until identified.
5. Propose Active six. If they have more, box the rest. Empty Sense is a hole.
6. Save the skills from this pack onto the shared computer.
7. Offer a Monday 08:00 gym: one brief, score the six, keep / box / rewrite never-list. They can paste INDEX.md back into the Field Guide.
8. Stop. Do not spawn a zoo.

If they paste an x.ai/bot URL, run identify-specimen. Do not open it and click Add.

If they ask for more bots, ask which Active slot dies first, or which cheap kill they will Release.

INDEX.md is the same file the Field Guide exports. Keep one schema.
