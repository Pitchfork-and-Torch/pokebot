# Skill: identify-specimen

When: user pastes a URL, a wish, a directory blurb, or an existing bot description.

Inputs: raw text. Optional: current Active six.

Sequence:
1. Strip never-clauses before scoring outbound/spend.
2. Score the eight types. Keep 1, or 2 if close.
3. Extract never-list lines.
4. Guess tools.
5. Verdict per PROFILE.md.
6. Write the card.

Validation: why has 2-4 lines. Verdict is CATCH, WATCH, or SKIP. No live IDs invented.

Output: the identify shape in PROFILE.md.

Approval: Catch is a recommendation. User adds the bot themselves.
