# Skill: team-of-six

When: after Index exists, or when Active is messy.

Inputs: INDEX.md.

Sequence:
1. Group by type.
2. Keep at most one primary per type unless the jobs are truly distinct.
3. Propose six pins.
4. Box the rest. Do not delete.
5. Name the hole (missing Sense, missing fence, etc.).

Validation: Active length <= 6. Cap math visible.

Approval: user accepts the board.
